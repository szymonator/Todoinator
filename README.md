# This app was fully vibecoded for personal use

I just wanted to help organise my life a bit and didn't want to pay for features like daily reminders and priority scheduling.

Priority is determined by a priority level from 1-5 and also by the time until deadline. A task with priority level 3 due in an hour will be prioritised over a task with priority level 5, due in a day.

Urgency Score = Base Priority × Decay Multiplier(H)
